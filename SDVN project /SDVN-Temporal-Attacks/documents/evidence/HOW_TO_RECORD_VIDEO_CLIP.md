## Steps to record

1. **Launch NetAnim** (from a terminal on your desktop, not through me):
   ```bash
   /home/sdvn_echo_topology/ns-allinone-3.35/netanim-3.108/NetAnim
   ```
2. In the NetAnim window: **File → Open** and select the XML path above.
3. Click the **Play** button (▶) in the NetAnim toolbar. You'll see vehicle
   nodes moving along the SUMO-derived trajectories, with the TTW-S1 attacker
   (red) and victim (cyan) highlighted, and packet arrows animating around
   t=10s (HELLO exchange) and the forged replay shortly after.
4. **Start screen recording** using whichever tool you have available:
   - **GNOME**: built-in screen recorder — `Ctrl+Shift+Alt+R` (or Settings →
     Keyboard Shortcuts → "Screen Recording"), stops with the same shortcut.
   - **SimpleScreenRecorder** or **OBS Studio**, if installed — select the
     NetAnim window/region as the capture source.
   - **ffmpeg** (not currently installed on this machine — install with
     `sudo apt install ffmpeg` if you'd like a command-line option) — once
     installed, this captures the whole screen for 20 seconds:
     ```bash
     ffmpeg -f x11grab -video_size 1920x1080 -framerate 30 -i :0.0 \
       -t 20 -c:v libx264 -pix_fmt yuv420p ns3_simulation_clip.mp4
     ```
     (adjust `-video_size` to your actual screen resolution, `xdpyinfo | grep dimensions`)
5. Let it play for ~15-30 seconds around the t=10-20s window (where the attack
   happens), then stop recording.
6. Save the clip alongside the other evidence files in this `evidence/` folder
